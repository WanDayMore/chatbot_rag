# Key Projects

## 1. Portfolio AI RAG Chatbot
- **Overview**: A custom, high-security RAG assistant powered by Google Gemini Pro and FastAPI.
- **Key Features**:
  - Semantic query caching preventing redundant token consumption by over 70%.
  - Multi-tier defense with strict CORS, Cloudflare Turnstile bot verification, and rate limiting.
  - Zero-cost architecture leveraging embedded ChromaDB and free-tier infrastructure.
  - Dual delivery: Server-Sent Events (SSE) streaming and REST JSON responses.
- **Tech Stack**: Python, FastAPI, Gemini API, ChromaDB, Cloudflare Turnstile, Docker.

## 2. Distributed Web Application
- **Overview**: High-concurrency web platform built with microservice architecture.
- **Key Features**:
  - Asynchronous background jobs and task scheduling.
  - End-to-end type safety from front-end to database models.
- **Tech Stack**: Next.js, FastAPI, PostgreSQL, Redis.
